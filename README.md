# Our Fourth Anniversary Game | Final Edition

Open index.html after extracting the entire ZIP. Keep assets beside it. No installation or dependencies. Alternatively use the separate self-contained HTML with all photos and video embedded.

All 4 levels are personalized. Level 2 quiz uses the exact requested options (Lalaport appears twice, intentionally preserved): Suria KLCC and IOI City Mall. Level 3 uses eight photos in upload order, two per year. Level 4 includes the original uploaded MP4 and the Saturday 21 November 2026 date invitation. No gifts are named. Captions are editorial suggestions, not factual dates or locations. New local storage key means this final edition begins fresh.

## Publish
Create a private Git repository and upload the contents of this folder (index.html and assets). Import it in Vercel; choose Other framework, no build command, root as output. Alternatively upload static files using your preferred hosting service. Ensure deployed site uses access protection if you need privacy. A private repository alone does not make a website private. A secret URL, noindex and sequential game levels are not access controls. Test on her device before sharing. The MP4 has original audio: use the video controls to play it. Game music is optional and pauses while video plays.
